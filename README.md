# Supply Chain & Retail Analytics Dashboard

## Project Overview

This project analyzes retail sales, profitability, products, customers, regions, and shipping performance using **MySQL, SQL, and Power BI**.

The goal was to transform raw retail transaction data into an interactive business intelligence dashboard that can help identify sales trends, profitability patterns, product performance, and shipping insights.

## Tools & Technologies

* MySQL
* SQL
* Power BI
* DAX
* Power Query
* Microsoft Excel

## Project Workflow

**CSV → MySQL → SQL Analysis → ODBC → Power BI → Interactive Dashboard**

## Key Analysis

* Overall sales and profit performance
* Monthly sales and profit trends
* Category and sub-category performance
* Top-performing and loss-making products
* Discount and profitability analysis
* Shipping mode and delivery performance
* Regional and state-level sales
* Customer and segment analysis

## Dashboard Pages

1. Executive Overview
2. Sales & Profit Analytics
3. Product & Inventory Analytics
4. Supply Chain & Shipping Analytics
5. Customer & Regional Analytics

## Key Features

* Interactive Power BI dashboard
* KPI cards
* Sales and profit trend analysis
* Product performance analysis
* Shipping and delivery analysis
* Customer and regional analysis
* Interactive filters for Region, Category, Ship Mode, and Segment

## Files

## Outcome

The project demonstrates an end-to-end analytics workflow, from data preparation and SQL analysis to interactive Power BI reporting and business insight generation.
